# Sound Files Directory

This directory contains sound files used in the Bedtime Stories application.

## Files

- `magical-ambience.mp3` - Ambient magical sound for the homepage background

## Usage

To use these sound files in the application, reference them with the path `/sounds/filename.mp3`.

Example:

```jsx
<audio src="/sounds/magical-ambience.mp3" />
```

## Notes

- Sound files should be optimized for web (compressed, reasonable file size)
- Consider providing alternative formats for better browser compatibility
- Always include user controls for sound or default to muted
